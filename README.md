# Hotel-Booking-Occupancy-Manager
Java project for managing hotel bookings, room details, and booking charges.
### Hotel Booking & Occupancy Manager

The **Hotel Booking & Occupancy Manager** is a Java-based application designed to manage hotel room bookings and calculate the total booking charges. The system allows users to enter customer details, select a room type, specify the number of rooms and number of days, and calculate the total cost of the booking.

The application provides different room categories such as **Standard, Deluxe, and Suite**, with different prices for each category. Based on the selected room type, number of rooms, and number of days, the system calculates the total booking amount. It can also categorize customers according to their booking amount.

The project demonstrates important Java programming concepts such as **classes and objects, methods, arrays, conditional statements, loops, user input, and calculations**. The system provides a simple and organized way to handle hotel booking information and demonstrates how Java can be used to develop a basic real-world management application.

## Project Overview

The project starts with a simple hotel booking program and gradually improves it by adding more features and programming concepts.

The four programs represent different stages of development:

1. HotelModule1.java – Basic hotel booking
2. HotelModule2.java – Improved booking and decision-making
3. HotelModule3.java – Extended booking functionality
4. HotelBookingManager.java – Complete integrated version

---

## 1. HotelModule1.java – Basic Booking System

### What was updated

The first version provides the basic functionality required for a hotel booking system.

It:
- Accepts the customer's name.
- Allows the customer to select a room type.
- Provides Standard, Deluxe and Suite options.
- Accepts the number of rooms.
- Accepts the number of days.
- Calculates the total booking amount.
- Displays the booking details.

### Java concepts used

- Variables and data types
- Scanner for user input
- Arithmetic operators
- `if-else` decision making
- Basic input and output

### Benefits

- Simple and easy to understand.
- Reduces manual calculation.
- Provides a basic structure for the project.
- Demonstrates how Java can be applied to a real-world problem.
