# Hotel-Booking-Occupancy-Manager
Java project for managing hotel bookings, room details, and booking charges.
### Hotel Booking & Occupancy Manager

The **Hotel Booking & Occupancy Manager** is a Java-based application designed to manage hotel room bookings and calculate the total booking charges. The system allows users to enter customer details, select a room type, specify the number of rooms and number of days, and calculate the total cost of the booking.

The application provides different room categories such as **Standard, Deluxe, and Suite**, with different prices for each category. Based on the selected room type, number of rooms, and number of days, the system calculates the total booking amount. It can also categorize customers according to their booking amount.

The project demonstrates important Java programming concepts such as **classes and objects, methods, arrays, conditional statements, loops, user input, and calculations**. The system provides a simple and organized way to handle hotel booking information and demonstrates how Java can be used to develop a basic real-world management application.
